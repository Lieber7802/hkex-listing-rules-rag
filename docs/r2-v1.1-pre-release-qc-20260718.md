# R2 v1.1 Pre-release Quality Control Record

**Status:** failed before release freeze; not eligible for formal evaluation or reporting.

## Inspected candidate pool

- Path: `data/evaluation/r2/v1.1/formal_pool_aa946cf_20260718/`
- Candidate count: 520
- Independent judge records completed: 517
- Static validation eligible candidates: 167

## Failure

The pool could not satisfy the published joint quota. In particular, the
`size_test_calculation` and `tool_chain` cells had material shortages.

Pre-release inspection identified two evaluation-infrastructure defects:

1. The generator produced `size_test_calculation` cases with a three-step tool
   chain and attached arbitrary source chunks. It also attached arbitrary
   sources to tool-chain cases, so the declared legal evidence did not support
   the intended regulatory consequence.
2. The independent-judge prompt did not distinguish deterministic tool evidence
   from source evidence, and it accepted internally contradictory scores (for
   example, a supported answer point paired with a grounding score of 1).

## Corrective action

Before any release is frozen or a system is evaluated, the generator and judge
contracts are corrected with regression tests. A new candidate pool will be
generated with a new seed and case-ID prefix, rechecked for R1 isolation, and
judged independently from scratch. No candidate, judge assessment, selection,
or metric from this failed pool may be used in the R2 results or paper.
